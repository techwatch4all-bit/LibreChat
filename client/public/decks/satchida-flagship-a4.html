Supply & deployment of the Satchida Sovereign AI workspace

1Executive summary

Satchida proposes the supply, deployment and support of a private AI workspace for your team. All cloud queries (Chat, Study, Work) leave through our Zero-Knowledge Relay — providers never see who asked. The Sovereign Privacy tier adds Privacy mode: 100% on-premise inference on your own ≥24GB GPU server. Billed in Rupees over NPCI rails with GST invoicing.

2Scope of the offer
  • Private workspace — tenant at ai.satchida.com; seats per the commercial option selected; runs on any phone, tablet or PC.
  • Working modes — Chat, Study and Work run on frontier cloud via the anonymizing relay in every tier; Privacy mode (on-premise) is exclusive to the Sovereign Privacy tier. Study mode: Socratic tutoring with POCSO-aligned filtering for minors; vault answers cite loaded study material page by page.
  • Developer toolchain — browser VS Code Server Web IDE (dual-screen), undocked artifacts, sandboxed Python/JS/shell execution, MCP tools, autonomous subagents; priority routing on every cloud query.
  • Satchida Knowledge Vault — per-seat isolated document workspaces, page-level citations, automated PPTX / PDF / DOCX / XLSX generation.
  • Onboarding — a Satchida engineer installs dependencies, deploys the platform and tests every mode; cloud options (A & B) typically go live within 7–10 working days of acceptance. Option C adds on-premise deployment on your own ≥24GB GPU server.
  • Dependency (Option C) — client-provided server: 1× RTX 3090/4090 (24GB) or Mac Studio ≥36GB · 32GB RAM · 1TB NVMe · Windows 11 Pro / Ubuntu 22.04 — or our turnkey workstation.
