## 2. The Hidden Danger of "Bring Your Own Cloud Account + API Key"

Some cost-conscious teams try to save money by signing up for a raw cloud AI or API aggregator account (like OpenRouter) and plugging their own API key into a free chat tool. **That shortcut turns everyday office work into a severe security and privacy liability.**

### What Just Happened: The OpenRouter / GMI Cloud Breach (Oct–Nov 2026)
In November 2026, OpenRouter warned customers that an attacker had breached one of its downstream model providers (**GMI Cloud**) for an entire month (October 21 – November 17, 2026):
- **Plaintext Prompt Retention**: An internal troubleshooting system quietly kept **~3 days of raw prompt content** from every model request.
- **Live Credential Theft**: The attacker searched those prompt logs for passwords, keys, and tokens. Security researchers who placed canary AWS keys inside prompts confirmed the attacker **harvested those keys and immediately used them to make live AWS calls**—attempting to create unauthorized users and backdoor keys.
- **Month-Long Blind Spot**: Customers were only notified on November 20 and told to treat all sent prompts as read by a third party and rotate every password, key, token, or signed URL that appeared in them.

### Why DIY Cloud Accounts Fail Teams — And How Satchida Protects You
- **No Unvetted Sub-Processors or Shadow API Keys**: With DIY API keys, staff paste client invoices, passwords, links, and internal documents into tools that silently route through third-party hosts you never approved. With Satchida, **no master API keys ever sit on employee devices**.
- **Zero-Knowledge Identity Stripping**: Every cloud request from your workspace passes through Satchida's Zero-Knowledge Relay, which strips your company identity, account, and origin before an upstream model ever sees the query.
- **Private Local Knowledge Vault**: Your office PDFs, circulars, spreadsheets, and client files are indexed in your own isolated LanceDB Knowledge Vault—not scattered across public cloud chats.
- **Upgrade Path to 100% Air-Gapped Privacy**: When your organization is ready for zero-egress confidentiality, Satchida's Sovereign Privacy tier runs inference 100% on-premise on your own GPU—eliminating cloud exposure completely.
