# Release package updates · v1.3.0 · 2026-11-09

- Added doc 18 "The medium layer and character entry": for films where "one scene passes through many drawing methods", split scene and method into two passes. The scene hands over only a color map, a region map, and stroke directions; the method paints stroke by stroke from those three; outlines draw only the visible segment; randomness keys on cells so a moving picture never re-shuffles wholesale.
- Added the reference implementation `scripts/engine/reference_films/painted_room/`: one room, one cat, 16 drawing methods (cave murals to pixel art), 44 seconds, with its own method engine, render script, and score. It renders directly even without character frames; drop in your own frames and every method repaints the character, with transitions triggered by the character's actions (pull, walk, jump, wave).
- The method and boundaries for walking existing character frames into different styles without regenerating are written into doc 18 section 6, with a pointer added after doc 10's method B.
