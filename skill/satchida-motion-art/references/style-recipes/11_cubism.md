# 11_cubism · 1912 Analytic Cubism (Picasso / Braque)

File: `scenes/11_cubism.js` (~280 lines). Performance: warm mean 13ms, max 19ms, first frame (cache build) ≈100ms; determinism passes; motion diff lt 0.34→0.46 moves 6.9% of pixels. Segment hold 0.47s (T10 shard transition 0.24s).

## Pipeline
1. **Base plate fully cached `cb_bg` — "transparent stacked planes"**: core function `plane(g, pts, col, alpha, r)`: each plane gets one linear gradient, start at vertex 0, end randomly at another vertex, three color stops = mix 25% cream → original → mix 40% dark brown, alpha 0.18–0.7. Stacking: 18 hand-placed large planes (positions per the original's composition) + 9 radiating fan panels under the table (from (1000,1090), bright/dark alternating α0.3) + 70 random 3/4-gons (avoiding the upper-right year zone). Multiple semi-transparent gradient layers stacked produce Analytic Cubism's "transparent, interpenetrating, each plane one bright one dark" space.
   - Texture planes: 4 stippled blocks (9px diamond grid r1.6), 4 hatched blocks (7px-spaced diagonals), one page of horizontal-line paper on the left edge.
   - Braque short-dash sand grain: 9000 small dashes 3–8×1.5px, 55% cream α0.28 / 45% dark brown α0.16 — the original's "brick texture" feel relies on this.
   - 46 fine straight lines crossing the frame (1.3px α0.55) = passage.
   - Faux wood grain `wood()`: S/6 wavy lines along the long edge, a Gaussian bump at each knot `14·exp(-(u-k)²/0.01)`, knots with 4 ellipse rings. Used on the tabletop and right plank (Braque's combed faux wood). Woven chair back = 10px diamond-hole dots + bidirectional diagonals.
2. **Window-pane facet sliding**: the window view cached separately as a 560×540 large image (55 blue-gray facets + 3 diagonal light beams + Eiffel Tower + seagull arcs); each of the four panes clips and views it at a different offset `dx = sin(9lt+1.7i)·18 + 10fps jitter ±3`, `dy = cos(7lt+i)·8` — one window scene misaligned across four panes = multi-view assembly; each pane also has a semi-transparent triangle sliding across horizontally at 260px/s.
3. **CAFÉ stencil letters jumping positions**: `AlfaSlabOne-400` 104px drawn into a small offscreen layer, 12fps stepping (`st=floor(lt·12)`), order table rotating `CAFÉ/ACFÉ/CAÉF/CFAÉ`, each step each letter y ±13, rotation ±0.11rad (via hash); then `destination-out` cuts horizontal/vertical breaks = stencil letters (breaks reveal the stacked planes below, more real than paper-colored bars).
4. **Newspaper JOU**: cached as a 300×190 small image (LibreBaskerville-700 84px "JOU" + 12px headline "LA BATAILLE / S'EST ENGAGÉ UN CHAT" + three columns of gray filler text), trembling at 8fps each frame (rotation ±0.0125rad, x ±1.5px), upper-right fold flipping with `sin(20lt)`.
5. **Characters = hand-written facetizer `facetize`**: RIG flat fill (fill mode, no lines) into an offscreen layer → read back that bounding box's pixels → jittered triangle mesh (each cell randomly picks a diagonal) → each triangle samples color at its centroid, `×(0.8+0.38·rand)` shading, plus one bright→dark gradient from vertex 0 to vertex 2 → **triangles are not clipped**, drawn straight back (skip when centroid alpha<120). Not clipping is the key: the silhouette edge is cut into zigzag straight segments and some triangles stick out past the outline — exactly Cubism's "planes overflowing the contour".
   - Girl cell 58 (large planes); the hair region gets a second fine pass at cell 26 cutting only "colors that look blond" (`only: R>150 && B<130 && R-B>60`); cat cell 26.
   - Vertices jitter ±8% of cell at 8fps, 16–35% of triangles jump shading ±12% (boil) → the characters "micro-move"; the original's frames 548–562 cat region does exactly this.
6. **After faceting, add Picasso-style structure**: the face gets two re-laid skin shading planes (faceting drags blond color into the face) + a blue-gray plane over the front half-face α0.82 + frontal almond eye (frontal eye on the profile face) + spiral ear + red lips; white collar with two shading triangles + three buttons; skirt with 8 radiating cut lines from the waist + alternating bright/dark wedges; outer contour in straight segments `segs()`, each segment extending 10–16px beyond both ends (lines escaping the boundary). Cat: hexagonal straight-line head contour, `bodyPts` straight-line body contour, yellow diamond eyes + vertical pupils, side triangle nose.
7. Topmost: 5 planes at α0.2 pressed over person and cat, misshifting with `sin(6lt)·8` — embedding the characters into the space instead of pasting them on the background.

## Pitfalls (important)
- **Non-determinism: the first frame differs from the rest.** Two causes stack, both only on frame one: (1) an offscreen layer needing `getImageData` is GPU-rasterized on first paint; after readback Chrome converts it to CPU raster with different antialiasing → different centroid colors → different triangle colors; (2) more importantly, the offscreen context's state (facetize's `lineJoin='round'`, segs' `lineCap='round'`) persists to the next frame; frame one uses default miter/butt. Fix: create layers with `getContext('2d',{willReadFrequently:true})`, and **at the start of each frame use `g.reset()` (clears pixels + state) instead of `clearRect`**. Only caught by hash-comparing "same lt rendered three times".
- At cell 34 the whole body becomes small triangles, like a low-poly 3D model, not Cubism; only 58 gives "large shading planes".
- The second hair-region fine pass initially used a circular clip, cutting half the face into gold too — fixed by adding the color-filtered `only`.

## Still improvable

- The original's palette is darker with stronger value contrast (more large deep-umber planes); this version leans bright.
