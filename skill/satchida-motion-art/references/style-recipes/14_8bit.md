# 14_8bit · 1985 8-bit pixel game

## Pipeline
1. **The whole frame paints on a 240×135 low-resolution canvas** (1 low pixel = 8 screen pixels; the original's measured pixel blocks are 8px), finally `imageSmoothingEnabled=false` and one `drawImage` upscaled ×8.
2. **Background painted per-pixel `fillRect`** (cached `8b_bg`): cross-dot wall = 6px grid of 3×3 crosses, alternate rows offset 3px; wood floor planks y=106–113, a black seam every 24px; bricks 16×6 + 1px seam, alternate rows offset 8, a beige highlight row on top and left edges (`#fbe2a6`). Sky inside the window uses 3 bands of blue (`#0856ef / #47c4f8 / #aae9fb`), with `(x+y)%2` checkerboard dithering on ±0.05 transition bands — the only way NES does gradients.
3. **Characters = RIG paths scaled to low resolution and filled → spriteize**: each part on its own layer (far arm / body-legs / hair / face / fringe / near arm; cat body / cat head); each layer:
   - `getImageData` → alpha < 110 becomes transparent (kills antialiasing) → the rest quantized to the 14-color character palette (nearest color);
   - outer contour gets a 1px black edge (any transparent pixel with an opaque 4-neighbor is painted black).
   **Per-layer outlining is the key**: outlining the whole figure once smears hair/face/arm into one blob; only per-part outlines give NES sprites their inner contours.
4. **All features are per-pixel dots** (eye 1×2 black + brow, cat eye 2×2 black + 1 white highlight upper-left, pink nose 1px, blush 2×1), positioned from RIG anchors divided by 8 and rounded.
5. **The mug doesn't use RIG.drawCup**: AA paths at 6px wide blur out; instead draw a 6×5 white cup + two red stripes + a 3px handle directly at low resolution, following `G.cup`.
6. **HUD drawn at full resolution**: `PressStart2P` 48px (1 font pixel = 6 screen pixels; 64px is too wide — WORLD 1-1 would collide with the apple icon), 8px black drop shadow; cat head/heart/apple icons are string bitmaps, 8×8 per glyph.

## Jeans
RIG.girl is a long dress; the 8-bit version draws blue pants with two `RIG.taper` segments (hip `G.hipSeat`→knee (1222,724)→ankle (1214,872), widths 92/76/56), far leg one shade darker `#0838a8` offset back 26px; white sneakers + one red stripe.

## Small loops (the segment holds only ~0.23s ≈ 11 visible frames; all stepped animation)
- Cat tail: 15fps four-pose cycle `[-0.55, 0, 0.55, 0]` (RIG.cat's tail parameter) — pixel animation's "a few frames alternating".
- HUD heart blink: lt 0.16–0.23 (≈ frame 630), swapping every 2 frames: full heart goes white, hollow heart goes full red.
- Potted plant jitter: leaves shift whole pixels `[0,1,0,-1]` within the same window.
- ? block popping a coin: lt 0.06–0.22 half-sine up 9px then back down.
- Cloud outside the window moves 1px left every 2 frames; pixel steam three columns of 1×2 dots, rising 1px per frame at 30fps, looping every 6px.

## Pitfalls hit
- RIG cat's head top reaches y≈535, covering the windowsill (window ends y=590). That's the shared armature's position — not moved; the 8-bit black outline makes the overlap more visible, but transitions depend on the standard composition, so it stays.
- `spriteize` reads non-premultiplied RGBA — don't divide by alpha again.
- Performance: warm frames 2.5–6ms, cold start 11ms.
